# U60 Pro Enhanced · 实验版

中兴 U60 Pro（MU5250）国行原厂系统上的**屏幕 UI + 原厂网页版增强**。保留中兴系统、基带、Wi-Fi 驱动和原厂界面，不是 OpenWrt 固件，也不是整机刷机包。

**当前 `v0.1.1-experimental`：仅接受国行 B28、Linux 5.15.185-perf、ARM64，且原厂文件指纹一致的设备。B27、港版/国际版和其他固件未做验证。** 开发机的功能验证不等于第二台全新设备已安装验收；首次安装流程目前经过模拟测试，尚未在第二台实机验证。不能接受网络中断或手动恢复操作的用户，请暂缓安装。


## 相比原厂增加了什么

| 模块 | 新屏幕 UI | 原厂网页版“增强功能” |
|---|---|---|
| 首页与显示 | 五个主页、流量/速率/时间/电池/信号/上游状态、主题和亮度 | 新增能力概览、底部分类导航 |
| Clash / Mihomo | 服务与分流开关、规则/全局模式、节点选择、测速 | 订阅新增/修改/删除/更新、更新间隔、策略组与节点、规则及本地规则、连接查看与关闭；URL 脱敏 |
| Tailscale | 开关、模式、设备、子网互通、出口选择等 | 更完整设备清单、健康/版本/密钥到期、主机名、发布路由、网络诊断；管理端审批仍在 Tailscale 后台 |
| Wi-Fi | 2.4G/5G 分别开关、热点信息、连接上游 Wi-Fi、中继配置保存 | 仅保留中继；热点基础设置使用原厂菜单 |
| USB 网口 | 手动 LAN 与 AUTO 上游 WAN 识别、状态与回退 | 同一角色设置与状态 |
| 电源与待机 | 保留电源键操作；充电/直供、待机服务策略与详情 | 同步充电状态和控制；危险能力按本机验收结果锁定 |
| 其他 | 流量账本、蜂窝信息与部分高级设置 | 原厂页面继续承担原有管理功能；增强页不宣称覆盖所有社区端点 |

**边界：** 透明代理的已验证范围是 IPv4 TCP 与 DNS；普通 UDP、IPv6 全量代理、所有业务场景的防泄漏没有完成验证。Tailscale 的双向子网访问需要管理端批准路由和访问策略，不会自动放开账号权限。Wi-Fi 中继现阶段使用 2.4GHz 上游与 5GHz 下游。USB AUTO 用于上游 WAN，**连接电脑作为下游必须选 LAN**，不是自动猜测电脑角色。

## v0.1.1 更新

优化深浅两套主题的文字对比与配色；可操作项前置，电池状态集中到详情，保留未验证功能的限制；网页去除与原厂重复的设置，分类菜单常驻底部，原厂侧栏的增强入口移至末尾。详见 [更新记录](docs/CHANGELOG.md)。

安装器仍用于首次安装，**没有自动覆盖旧版的升级命令**；已有安装请先阅读更新边界，勿删除配置后重装。

从本仓库 **Releases** 下载 `u60-pro-enhanced-v0.1.1-experimental.tar.gz`，核对同页 `SHA256SUMS.txt`。GitHub 的自动 Source code 包是源码，不含编译程序；需要自行构建。

安装包没有任何现成节点、订阅、密码、Tailscale 身份、SSH 私钥或开发机配置。首次默认直连、普通待机、USB LAN；保留目标机原有 Wi-Fi 频段设置。**不会替你升级固件、解锁 ADB 或创建云端账户。** 需要用户自己完成设备解锁及配置。

原厂网页和字体不再分发：准备工具在 USB 连接时，从目标设备读取三份固定的原厂静态网页文件，验证指纹后生成本地覆盖层；安装不改写原厂网页分区。Mihomo、Tailscale 和规则数据从各自官方来源下载，固定版本及 SHA-256 见 `packaging/dependencies.json`。准备目录只留在自己的电脑，**不要上传或转发**。

## 从源码构建

依赖：Zig 0.14.1、Go 1.26.5、Python 3、Git；主机测试还需 C 编译器与 Node.js。官方 Zig/Go 工具链请自行安装。

```sh
sh scripts/build.sh
sh scripts/test.sh
python3 scripts/package.py
```

可通过 `ZIG=/path/to/zig GO=/path/to/go sh scripts/build.sh` 指定编译器。结果位于 `dist/`。源码完整提供；`sdk/stub.c` 仅用于生成链接 SONAME，运行时使用目标设备自己的库，不分发中兴动态库。预编译程序不包含编译机绝对路径。
