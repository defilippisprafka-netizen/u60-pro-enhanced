# 更新记录

## v0.1.1-experimental · 2026-09-22

### 屏幕 UI

- 深色主题提高辅助文字对比度，并以蓝、青、紫区分网络、设备和服务卡片；浅色主题降低背景亮度并调整文字颜色。
- 设置项按可操作、只读状态、暂不可用分组；不改变操作参数或绕过验证门槛。
- 电池与省电整理为充电与直供、充电上限、USB-C 供电方向、待机服务策略、电池与待机详情。运行信息和未验证原因进入详情，异常状态仍突出显示。
- 修正已能操作的原厂设置中沿用的“状态不可读”等旧提示；SIM 页面明确为状态页。

### 原厂网页增强

- 移除与原厂重复的热点、蜂窝/APN、路由/DHCP/DNS/防火墙、短信、SIM 基础状态和套餐设置入口，原厂对应菜单继续使用。
- 保留完整 Clash/Tailscale 管理、Wi-Fi 中继、USB 网口角色、充电与深待机、频段/信号工具和代理连通性诊断。
- 分类菜单固定在页面底部，原厂侧栏的“增强功能”移至末尾；适配手机和桌面，避免原厂样式覆盖选中菜单。
- 屏幕独立套餐账本仍保留，未删除既有记录；不与原厂套餐账本自动同步。

### 验证与限制

开发机 B28 已验收屏幕启动与菜单、网页 375px/1280px 布局、原厂页面访问、订阅表单及组网高级状态。公共源码重新编译，新增菜单布局/高级提示/网页过滤和嵌套导航测试；公开版本仍不携带开发机配置或验收标记。

本轮是展示与提示更新，未扩大联网、射频、充电或待机的已验证范围。第二台新机首装、长待机耗电、充电完整周期、所有上游组合等限制见 [VALIDATION.md](VALIDATION.md)。

**安装包仍为首次安装流程，没有通用无损升级工具。** 已有 v0.1.0 或其他改装的设备不能直接执行首装覆盖；先保留原配置和备份，按源码差异制定单独更新方案。不要删除项目目录、订阅或 Tailscale 身份来绕过安装保护。
