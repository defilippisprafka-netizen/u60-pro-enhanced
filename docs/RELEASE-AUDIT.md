# 首版发布审查记录

日期：2026-09-22。范围为此公开源码与 `v0.1.0-experimental` 安装包；不代表所有未来提交都已审查。

- 从明确的源文件清单新建公开目录，未导入开发仓库历史、远端配置、设备备份、诊断记录或个人截图。
- 没有包含订阅链接、代理节点、Wi-Fi 密码、管理密码、Clash 控制密钥、Tailscale 身份/私钥、SSH 私钥或设备序列号。配置示例只有空账号结构、标准私网和公共 DNS。
- 移除了私人节点名称、编译机路径和测试中曾沿用的开发机网络地址；测试保留人工构造的无效域名与占位密码，用于检测脱敏是否生效。
- 新设备重新生成自己的 Clash 密钥并登录自己的 Tailscale。新设备不会继承开发机的充电/密码修改验收标记。
- 自有程序由公开源码重新构建：C 程序剥离调试信息，Go 使用 `-trimpath -ldflags '-s -w'`。检查二进制中的开发机路径、姓名和已知私人地址残留。
- Gitleaks v8.30.1 扫描公开源文件和安装目录，无凭证告警；同时人工核对配置类代码、URL 与测试占位信息。扫描降低泄露风险，不是数学意义的绝对保证。
- 安装归档采用通用 UID/GID、不包含用户名和系统扩展元数据，拒绝符号链接、绝对路径和路径穿越；归档不携带原厂页面、字体、动态库、设备配置或第三方网络核心。
- 从上游实际下载并校验锁定的 Mihomo、Tailscale 和三份规则；以固定的原厂静态资源测试了准备流程，未向开发设备重新安装。开发设备的9项原厂/库指纹只读核对一致。
- ARM64构建、Go控制器测试、网页模型与权限测试、135项控制层场景、Clash/网络协调/Tailscale/USB/Wi-Fi/待机/充电策略测试、安装与回退模拟、准备流程拒绝篡改测试通过。示例配置通过 Mihomo v1.19.31 语法验证。

第二台实机首装、完整账号初始化、整夜待机功耗、充电完整周期等仍未验证，具体见 VALIDATION.md。后续贡献与 issue 同样需要脱敏，不上传个人 prepared 目录或运行配置。
